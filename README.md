## Структура репозитория
- `/backend` — серверная часть (API, модели БД, тесты)
- `/web-dashboard` — веб-панель для Министерства труда и соцзащиты
- `/mobile-app` — мобильный клиент для социального работника
- `/docs` — техническая документация, схемы БД и тест-кейсы QA
Связь с трекером задач настроена.
