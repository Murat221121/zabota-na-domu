# Функциональные тест-кейсы («Забота на дому»)

## ТК-01: Фиксация статуса визита
- **Шаги:** Открыть карточку подопечного -> Нажать «Пришел» -> Отметить пункты чек-листа -> Нажать «Ушел».
- **Ожидаемый результат:** Статус визита обновлен в БД и отображается в веб-панели.

## ТК-02: Отправка экстренного сигнала SOS
- **Шаги:** Нажать кнопку SOS в карточке подопечного.
- **Ожидаемый результат:** Запрос отправлен на `/sos`, в веб-панели появился статус инцидента.
